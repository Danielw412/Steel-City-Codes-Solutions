# Steel City Codes Python Solutions

Instructor-facing complete Python solutions for the beginner command-line projects.

Each project folder contains three runnable Python solutions:

- `solution_1_basic.py`
- `solution_2_functions.py` or another descriptive second version
- `solution_3_alternate.py` or another descriptive third version

Run a solution from a terminal:

```bash
cd projects/magic_8_ball
python solution_1_basic.py
```

Use `python3` if your computer uses that command for Python 3.

## Projects

- Magic 8 Ball
- Rock Paper Scissors
- Chatbot
- Tic-Tac-Toe
- Hangman
- Connect 4
- Adventure Map

All solutions use terminal input and printed output.
